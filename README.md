This repository contains all the scripts, data and instructions to reproduce our results.

- The sample concentrations we measured can be found in the file `sample_datasheet.xlsx`.

- The jupyter notebook `publication_plots.ipynb` contains all the code necessary to remake the plots we present in the manuscript.
- The jupyter notebook `BannerHanson.ipynb` contains all the code necessary to reproduce our diagenesis modeling results.
- The `data\` directory contains all the external datasets that we use, and scripts to reduce our raw ICPMS data.
